# 📊 Sales Analytics Dashboard

An end-to-end Data Analytics project built using **Excel, SQL, Python (Pandas), and Power BI**.
This project transforms raw sales data into meaningful business insights through data cleaning, analysis, visualization, and an interactive dashboard.

---

## 🛠️ Tech Stack

- 📗 Microsoft Excel
- 🗄️ SQL
- 🐍 Python (Pandas)
- 📊 Power BI

---

## 📂 Dataset

The dataset contains sales transaction records with the following fields:

- Order ID
- Order Date
- Ship Date
- Geography
- Category
- Product Name
- Sales
- Quantity
- Profit

### 📌 Feature Engineering (Excel)

Created additional columns to improve analysis:

- 📅 Month
- 📆 Year
- 🚚 Shipping Days
- 💹 Profit Margin (%)

## 💡 Key Insights

- Identified the highest-performing products and categories.
- Analyzed monthly and yearly sales trends.
- Compared regional sales performance.

- Measured shipping efficiency using Shipping Days.
- Designed an interactive dashboard to support business decisions.
